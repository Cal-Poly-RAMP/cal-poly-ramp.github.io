### *Please Have VS Code Installed* 

# VS Setup

## Please add the following extensions in VS Code 
### [Verilog/SystemVerilog Sytntax Highlighting](https://marketplace.visualstudio.com/items?itemName=mshr-h.VerilogHDL) 
 - Enforces syntax
 - Autcompletes block headers 

### [VaporView Wave Viewer](https://marketplace.visualstudio.com/items?itemName=lramseyer.vaporview) 
 - Allows user to save state
 - Can change signals color and names
 - UI is quirky (must right click on certain parts of screen to access menus) 

### [Surfer Wave Viewer](https://marketplace.visualstudio.com/items?itemName=surfer-project.surfer) 
 - Doesn't allow user to save state (odd bug)
 - Menu and settings are easily accessible 
  
### [WSL Extension](https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-wsl) 
 - Able to open folders in WSL in your IDE
