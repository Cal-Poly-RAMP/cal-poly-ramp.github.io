ASIC VS Setup
=============

.. note::
   **Please have VS Code installed before proceeding.**

Required Extensions
===================

Verilog/SystemVerilog Syntax Highlighting
-----------------------------------------
`Verilog/SystemVerilog Syntax Highlighting <https://marketplace.visualstudio.com/items?itemName=mshr-h.VerilogHDL>`_

- Enforces syntax
- Autocompletes block headers

VaporView Wave Viewer
---------------------
`VaporView Wave Viewer <https://marketplace.visualstudio.com/items?itemName=lramseyer.vaporview>`_

- Allows user to save state
- Can change signals color and names
- UI is quirky (must right click on certain parts of screen to access menus)

Surfer Wave Viewer
------------------
`Surfer Wave Viewer <https://marketplace.visualstudio.com/items?itemName=surfer-project.surfer>`_

- Doesn't allow user to save state (odd bug)
- Menu and settings are easily accessible

WSL Extension
-------------
`WSL Extension <https://marketplace.visualstudio.com/items?itemName=ms-vscode-remote.remote-wsl>`_

- Able to open folders in WSL in your IDE
